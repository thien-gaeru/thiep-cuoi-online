# 💍 Thiệp Mời Cưới Web Online — Kho 100 Mẫu Thiệp Tùy Chỉnh

## ✨ Các Tính Năng Độc Đáo

* **Đổi mẫu tức thì (1-Click Switch)**: Bấm nút **"100 Mẫu Thiệp"** để đổi sang bất kỳ mẫu nào mà **không làm mất** nội dung hay ảnh cưới đã tải lên.
* **Tùy chỉnh toàn diện thông tin**:
  * Tên cô dâu, chú rể, cha mẹ hai bên.
  * Ngày giờ hôn lễ, lịch âm, sảnh tiệc, địa chỉ, định vị Google Maps.
  * Tải ảnh bìa, ảnh đại diện, tải nhiều ảnh cùng lúc vào album cưới (tự động nén siêu tốc bằng Canvas).
  * Tự động tạo mã VietQR theo số tài khoản ngân hàng bất kỳ.
* **Cá nhân hóa tên người nhận qua link (`?to=Tên_Khách`)**:
  * Tự động chào đúng tên khách khi mở thiệp.
  * Có sẵn bộ sinh link và mã QR quét mở trực tiếp trên điện thoại.
* **Mở bì thư tương tác & Nhạc cưới**:
  * Hiệu ứng vỡ dấu sáp, pháo hoa giấy confetti và phát nhạc piano lãng mạn.
* **Xuất file HTML tĩnh độc lập**:
  * Gom toàn bộ 100 mẫu, CSS, JS thành đúng 1 tệp HTML duy nhất để lưu trữ hoặc gửi trực tiếp.

## 🚀 Hướng Dẫn Chạy & Phát Triển Cục Bộ

1. Chạy máy chủ đồng bộ thời gian thực:
   ```powershell
   python server.py
   ```
2. Mở trình duyệt tại:
   * Trên máy tính: `http://localhost:8080`
   * Trên điện thoại (cùng mạng Wi-Fi): `http://192.168.31.79:8080`
